Run an analysis

  1. Extract the ZIP and open RodentVision.exe.
  2. Select a supported V21 .pth checkpoint and drop in a video.
  3. Choose an export folder, then click Run inference.

What you’ll need

Bring a compatible V21 model project and checkpoint, plus a Python environment with PyTorch, torchvision, and OpenCV. Review video export requires FFmpeg.
